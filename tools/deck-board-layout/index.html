    DECK LAYOUT GUIDE

    Plan how deck boards will land before fastening the first one

    Deck boards rarely divide perfectly across the finished deck width. If you simply start with a full board, the last board may become an unattractive narrow rip. This calculator lets you compare a full-board start with a balanced layout that shares the cut between both edges.

    Use the installed dimensions

    Measure the total finished width perpendicular to the board direction. Enter the actual visible board face width and the installed gap you intend to maintain. MeasureMarks calculates each board start and, in balanced mode, adjusts the two edge boards equally.

    Example: Across a 12-foot deck using 5½-inch boards and a ¼-inch installed gap, the remaining width may produce narrow edge material. Balanced mode shows whether splitting that remainder creates two better edge boards.

    Before fastening boards

    • Use the actual board width; wood and composite decking can differ from nominal dimensions.
    • Choose a gap based on the decking manufacturer’s requirements and expected installed condition.
    • Check the calculated edge-board width before starting, especially around fascia, picture framing, or border boards.
    • Re-check the deck width in several locations if the framing is not perfectly square.

    Why balance the edge boards?

    Two similar edge cuts usually look intentional and avoid ending the deck with one very narrow strip.

    Does this calculate board length or material quantity?

    No. It plans the cross-deck board layout and start marks; board lengths and waste depend on the deck shape and fastening pattern.
