    CABINET HARDWARE GUIDE

    Map cabinet pull and knob holes before drilling

    Cabinet hardware is unforgiving: a hole that is a quarter inch off is permanent. This calculator treats each door or drawer front as a measured rectangle and places the hardware from independent horizontal and vertical edge offsets. The drawing preserves the real shape of the part, so a wide drawer front looks different from a tall cabinet door.

    How to define the hardware position

    Enter the part width and height, choose knob or pull, then choose the corner or centered placement. For pulls, enter the manufacturer’s center-to-center hole spacing and choose horizontal or vertical orientation. Horizontal and vertical offsets are independent so the hardware can be positioned exactly where you want it.

    Example: An 18×28-inch upper door can place a vertical 5-inch pull 2½ inches from the right edge and 3½ inches from the top edge. MeasureMarks returns both drill-hole X/Y coordinates and shows them on a proportional door drawing.

    Before drilling

    • Measure the actual door or drawer front, not the cabinet-box opening.
    • Confirm pull hole spacing from the hardware itself or the manufacturer drawing.
    • Use a sharp template or drilling jig when repeating the same placement across multiple doors.
    • Test the layout on one part before drilling an entire kitchen.

    What happens if a pull will not fit?

    The calculator now rejects positions that would put a drill hole outside the cabinet part.

    Where are X and Y measured from?

    X is measured from the left edge and Y from the top edge, matching the coordinates shown on the blueprint.
