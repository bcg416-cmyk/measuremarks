    FENCE LAYOUT GUIDE

    Lay out pickets from the opening you actually have

    Fence picket spacing is easy to get wrong when the opening is not an even multiple of the picket width. This calculator starts with the real clear opening, the actual picket width, and the maximum gap you want. It then finds a practical picket count and produces the center mark for every picket.

    Maximum gap versus actual gap

    The maximum gap is a limit, not a target. MeasureMarks increases the picket count until the calculated clear gap is at or below that limit. The result section shows the actual finished gap and the center-to-center spacing so you can verify the layout before fastening anything.

    Example: If an opening is 8 feet wide, the pickets are 3½ inches wide, and you do not want a gap larger than 3 inches, the calculator chooses the needed count and distributes the remaining space evenly.

    Before you mark the rail

    • Measure between the finished inside faces of the posts or other true boundaries.
    • Use the actual picket width; nominal lumber sizes can differ from the installed face width.
    • Choose flush ends only when the first and last pickets should touch the boundaries.
    • Check local requirements where fence opening size matters for safety or code.

    Why are the marks measured from one side?

    Using one datum edge prevents cumulative error that can occur when each picket is measured from the previous one.

    Can I use this for privacy fences?

    Yes, as long as the layout is a straight run and the pickets use a consistent width and gap rule.
